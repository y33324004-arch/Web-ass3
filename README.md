# My Tech Blog - Semantic HTML5 & Multimedia

A responsive and accessible blog webpage built using **Semantic HTML5** elements, multimedia embedding, and web accessibility best practices.

##  Project Overview
This project was created as part of the **Web Development 1** course (Week 03 Assignment). It demonstrates the proper usage of HTML5 semantic structure to improve SEO, accessibility, and code maintainability.

##  Key Features
* **Semantic Structure:** Uses `<header>`, `<nav>`, `<main>`, `<article>`, `<aside>`, and `<footer>` instead of generic `<div>` containers.
* **Rich Content Elements:** Includes `<figure>` with `<figcaption>` for descriptive images, and `<time>` for machine-readable dates.
* **Multimedia Embedding:** Embeds an educational YouTube tutorial using a responsive `<iframe>`.
* **Accessibility (a11y):** Implements `aria-label` attributes, descriptive `alt` text for images, and proper heading hierarchy (`<h1>` to `<h3>`).
* **HTML Entities & Metadata:** Uses proper HTML entities (such as `&copy;`) and essential `<meta>` tags for viewport and SEO description.

##  Technologies Used
* **HTML5**

##  How to Run
1. Clone or download this repository.
2. Open `blog-page.html` in any modern web browser (Chrome, Firefox, Edge, Safari).
